# Шаблоны файлов спецификации (frontend)

Справочник шаблонов для `/spec-absolut-init`. Читай этот файл перед генерацией раздела.
Правила единственного владения фактом — в [SKILL.md](../SKILL.md), раздел «Единственный источник факта». Соблюдай их: колонки, помеченные «только ссылка», не раскрывай подробно.

- Guards указывай **только по имени**; условия и redirect'ы — в `navigation.md`.
